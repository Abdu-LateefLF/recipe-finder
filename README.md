# AI Recipe Finder

Ever stared into the fridge, wondering what to cook? Just list the ingredients you have, and let AI suggest creative recipes for you!

This full-stack, AI-powered recipe recommender helps you discover meal ideas based on what's already in your kitchen. Built with Node.js, React, MongoDB, and the OpenAI API for smart, ingredient-based recipe generation.

🚀 Features

- AI-Powered Suggestions: Generate unique recipes based on available ingredients.
- User Authentication: Secure login and registration system.
- Search History: Save and manage previous ingredient searches.
- Responsive UI: Optimized for both desktop and mobile experiences.

Short demo on how it works! You can try it yourself [here](https://airecipefinder.vercel.app/)

### 📂 Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Abdu-LateefLF/recipe-finder
   ```
2. Install dependencies for the backend and frontend:
   ```bash
   cd backend && npm install
   cd ../frontend && npm install
   ```
3. Add your environment variables (API keys, database URI, etc.) in a .env file.
4. Start the development servers:
   ```bash
   cd backend && npm start
   cd ../frontend && npm start
   ```
